Welcome to my Artificial Intelligence and Machine Learning internship repository. This project documents my progress through fundamental programming, data analytics, predictive modeling, natural language processing, and Generative AI applications.

---

## 🎯 Key Topics Covered

* **Python Fundamentals & Data Structures:** Control flow, functions, recursion, lambda expressions, lists, tuples, sets, dictionaries, and Object-Oriented Programming (OOP).
* **Exception Handling & Utilities:** Robust error handling (`try-except-else-finally`), custom exceptions, and built-in modules (`math`, `random`).
* **Numerical Computing with NumPy:** Array creation, indexing, slicing, broadcasting, linear algebra, and statistical operations.
* **Exploratory Data Analysis (EDA):** Data profiling, missing value imputation, duplicate removal, distribution analysis, and correlation heatmaps.
* **Feature Engineering & Preprocessing:** Categorical encoding (One-Hot Encoding), feature scaling (`StandardScaler`), and train-test splitting.
* **Supervised Machine Learning:**
  * **Regression:** Linear Regression, $R^2$ score evaluation, and model serialization with `joblib`.
  * **Classification:** Logistic Regression, Decision Trees, SVM, $K$-Nearest Neighbors, Naive Bayes, Confusion Matrix evaluation, and Classification Reports.
  * **Ensemble Methods:** Random Forest, AdaBoost, Gradient Boosting, XGBoost, and hyperparameter tuning using `GridSearchCV` and `RandomizedSearchCV`.
* **Unsupervised Learning:** K-Means Clustering (Elbow Method), DBSCAN, and Principal Component Analysis (PCA) for dimensionality reduction.
* **Natural Language Processing (NLP):** Text preprocessing, Bag-of-Words, TF-IDF vectorization, and Naive Bayes sentiment/emotion classification.
* **Generative AI & LLMs:** API key management, parameter tuning (`temperature`, `max_tokens`), model comparisons (Groq & Mistral), and building interactive AI assistants using LangChain.
* **Web Deployment:** Interactive machine learning dashboards built and deployed using Streamlit.
